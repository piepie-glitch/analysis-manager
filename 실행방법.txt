  분석 프로세스 매니저 - 실행 방법
═══════════════════════════════════════════════

[ 1단계 ] Node.js 설치 (최초 1회만)
─────────────────────────────────────
1. 웹 브라우저에서 https://nodejs.org 접속
2. "LTS" 버전 다운로드 (왼쪽 버튼, 추천 버전)
3. 다운로드된 파일 실행 후 "Next" 계속 클릭
4. 설치 완료

[ 2단계 ] 라이브러리 설치 (최초 1회만)
─────────────────────────────────────
1. Windows 탐색기에서 이 폴더 열기
   → C:\Users\abo\Documents\analysis-manager
2. 주소창에 "cmd" 입력 후 Enter
3. 아래 명령어 입력 후 Enter:
   npm install
4. 설치 완료 메시지 기다리기 (1~2분)

[ 3단계 ] 실행
─────────────────────────────────────
1. 같은 cmd 창에서 아래 명령어 입력:
   npm run dev
2. 브라우저가 자동으로 열림
   (안 열리면 브라우저에서 http://localhost:3000 접속)
3. 종료할 때: cmd 창에서 Ctrl + C

[ 매일 사용 시 ]
─────────────────────────────────────
1. 탐색기에서 이 폴더 → 주소창에 "cmd"
2. npm run dev
3. 브라우저 열림

[ 데이터 저장 위치 ]
─────────────────────────────────────
데이터는 브라우저의 로컬 저장소(localStorage)에
자동으로 저장됩니다.
→ 같은 컴퓨터, 같은 브라우저라면 새로고침해도 유지

[ 주의사항 ]
─────────────────────────────────────
- 브라우저 캐시/쿠키 삭제 시 데이터도 삭제됨
- 다른 컴퓨터와 데이터 공유 불가 (현재 로컬 버전)
- 회사 서버 배포는 별도 작업 필요
